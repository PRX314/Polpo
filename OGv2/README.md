## 🔍 Highlights Principali

### Innovazioni Identificate
1. **Menu Olimpiadi Goliardiche**: Drink creati dalle squadre entrano nel menu reale dei bar
2. **Doppio Linguaggio**: Ogni gioco ha versione moderna + arcaica
3. **Database Domande**: 45 domande categorizzate per "Sussurro delle Sirene"
4. **Quiz Paradossale**: Unico nel suo genere - risposta sbagliata più coerente vince
5. **Integrazione Google Sheets**: Sistema di classifica real-time

### Pattern Ricorrenti
- Documentazione foto/video obbligatoria
- Valutazione sempre su 3 criteri (0-5 punti ciascuno)
- Coinvolgimento pubblico esterno frequente
- Materiali umili per costruzioni (cannucce, carta)
- Durata performance standardizzata (30 sec - 2 min)
